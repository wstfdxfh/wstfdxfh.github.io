SuperManager 插件 · 突击复习笔记#

UE5 编辑器扩展插件，功能涵盖：资产管理、材质快速创建、Actor 批量操作、选择锁定系统。 插件类型：Editor Module（仅编辑器加载），入口：FSuperManagerModule

一、Content Browser 右键菜单扩展#

🔌 嵌入编辑器#

通过 FContentBrowserModule 的 Extender 委托数组，注册自定义右键菜单项：

1
2
3
4

// 获取 ContentBrowser 模块 → 拿到菜单扩展器数组 → 添加自己的委托
FContentBrowserModule& CBModule = FModuleManager::LoadModuleChecked<FContentBrowserModule>("ContentBrowser");
CBModule.GetAllPathViewContextMenuExtenders().Add(
    FContentBrowserMenuExtender_SelectedPaths::CreateRaw(this, &FSuperManagerModule::CustomCBMenuExtender));

在回调中用 FExtender 把菜单项插到内置 “Delete” 之后：

1
2

MenuExtender->AddMenuExtension(FName("Delete"), EExtensionHook::After, nullptr,
    FMenuExtensionDelegate::CreateRaw(this, &FSuperManagerModule::AddCBMenuEntry));

⚙️ 功能实现#

三个菜单项：

菜单项 功能
Delete Unused Assets 遍历文件夹下所有资产，用 FindPackageReferencersForAsset 检查引用数 = 0 的资产，调用 ObjectTools::DeleteAssets 批量删除
Delete Empty Folders 用 ListAssets 递归列出子文件夹，DoesDirectoryHaveAssets 判空后 DeleteDirectory
Advance Deletion 打开自定义 Tab（见下文）

共通的环境准备：删除前先调 PrepareAssetEnvironment → 修复重定向器 + 保存资产 + 保存当前关卡。

二、Advance Deletion Tab（自定义 Slate 面板）#

🔌 嵌入编辑器#

用 FGlobalTabmanager 注册一个 NomadTab（可停靠浮动面板）：

1
2

FGlobalTabmanager::Get()->RegisterNomadTabSpawner(FName("AdvanceDeletion"),
    FOnSpawnTab::CreateRaw(this, &FSuperManagerModule::OnSpawnAdvanceDeletionTab));

点击右键菜单时 TryInvokeTab 唤起面板。面板关闭时通过 SetOnTabClosed 回调清理状态。

⚙️ 功能实现#

核心是一个继承 SCompoundWidget 的 SAdvanceDeletionTab，布局结构：

1
2
3
4
5

SVerticalBox
├── STextBlock（标题）
├── SComboBox（筛选下拉框：全部 / 未使用 / 同名）
├── SScrollBox > SListView（资产列表）
└── SHorizontalBox（Delete All / Select All / Deselect All 按钮）

关键点：

  • SListView 通过 OnGenerateRow 为每行生成：CheckBox + 资产类型 + 资产名称路径 + Delete 按钮
  • 下拉框切换时调用 ListUnusedAssetsForAssetList（按引用数过滤）或 ListSameNameAssetsForAssetList（用 TMultiMap 按名字分组，取 count > 1 的）
  • 点击行 → SyncBrowserToObjects 在 Content Browser 中定位对应资产
  • CheckBox 勾选状态变化 → 维护 AssetDataToDeleteArray，Delete All 时批量删除

三、Quick Asset Actions（资产右键脚本动作）#

🔌 嵌入编辑器#

继承 UAssetActionUtility，函数标记 UFUNCTION(CallInEditor) → 自动出现在资产右键 “Scripted Asset Actions” 菜单中（无需手动注册）。

⚙️ 功能实现#

功能 实现
DuplicateAssets UEditorAssetLibrary::DuplicateAsset 循环复制，路径加 _1, _2... 后缀
AddPrefixes 维护一个 TMap<UClass*, FString> 前缀表（BP_, SM_, M_, T_ 等），GetClass() 查表后 RenameAsset
RemoveUnusedAssets FindPackageReferencersForAsset 检查引用，引用数 = 0 → ObjectTools::DeleteAssets

前缀表示例：{UBlueprint → "BP_", UStaticMesh → "SM_", UMaterial → "M_", UTexture2D → "T_", ...}

四、Quick Material Creation（材质快速创建）#

🔌 嵌入编辑器#

继承 UEditorUtilityWidget → 在编辑器中创建对应的 Editor Utility Widget 蓝图（WBP_QuickMaterialCreationWidget），通过 Run Editor Utility Widget 打开。蓝图中暴露的 UPROPERTY 自动生成 UI 控件。

⚙️ 功能实现#

选中多张贴图 → 自动识别类型 → 创建材质并连线：

  1. 识别贴图类型：根据文件名后缀匹配（如 _BaseColor, _Normal, _Roughness, _arm 等），每种类型维护一个 TArray<FString> 关键词数组
  2. 创建材质资产：UMaterialFactoryNew + AssetToolsModule.CreateAsset
  3. 创建节点并连线：为每张贴图 NewObject<UMaterialExpressionTextureSample>，根据类型连接到材质的对应 Pin：
1
2
3
4
5

// 以 BaseColor 为例
TextureSampleNode->Texture = SelectedTexture;
CreatedMaterial->GetExpressionCollection().AddExpression(TextureSampleNode);
CreatedMaterial->GetExpressionInputForProperty(MP_BaseColor)->Connect(0, TextureSampleNode);
// 非颜色贴图额外设置：SRGB=false, SamplerType=LinearColor
  1. ORM 通道打包模式：一张 ORM 贴图通过不同输出通道 (R/G/B) 分别连 AO、Roughness、Metallic：
1
2
3

CreatedMaterial->GetExpressionInputForProperty(MP_AmbientOcclusion)->Connect(1, TextureSampleNode); // R
CreatedMaterial->GetExpressionInputForProperty(MP_Roughness)->Connect(2, TextureSampleNode);        // G
CreatedMaterial->GetExpressionInputForProperty(MP_Metallic)->Connect(3, TextureSampleNode);         // B
  1. 可选创建材质实例：UMaterialInstanceConstantFactoryNew 创建 MI，SetParentEditorOnly 关联父材质

五、Quick Actor Actions（Actor 批量操作）#

🔌 嵌入编辑器#

同样继承 UEditorUtilityWidget，蓝图化后通过 Run Editor Utility Widget 使用。暴露的 UPROPERTY 包含丰富的参数控件（轴向枚举、旋转范围、缩放范围等）。

⚙️ 功能实现#

功能 实现
SelectAllActorsWithSimilarName 选中一个 Actor → 去掉名字末尾的数字后缀得到 NameToSearch → 遍历关卡所有 Actor，StartsWith 匹配则选中
RandomizeActorTransform 对选中的 Actor 随机化旋转/缩放/偏移：FMath::RandRange 生成随机值 → AddActorWorldRotation / SetActorScale3D / AddActorWorldOffset
DuplicateActors EditorActorSubsystem->DuplicateActor 复制 → 按指定轴向（X/Y/Z 枚举）和间距 AddActorWorldOffset 排列

🔌 嵌入编辑器（三个入口）#

① Level Editor 右键菜单：类似 Content Browser 的扩展方式

LevelEditorModule.GetAllLevelViewportContextMenuExtenders().Add(...);

② 快捷键：通过 TCommands + FUICommandList 注册

1
2

// 注册命令（SuperManagerUICommands.cpp）

③ Scene Outliner 自定义列：锁定图标 + 每行 CheckBox（详见下文）

⚙️ 功能实现#

核心机制：Actor Tag

1
2
3

void LockActorSelection(AActor* Actor)   { Actor->Tags.Add(FName("Locked")); }
void UnlockActorSelection(AActor* Actor) { Actor->Tags.Remove(FName("Locked")); }
bool CheckIsActorSelectionLocked(AActor* Actor) { return Actor->ActorHasTag(FName("Locked")); }

拦截选中事件：在 StartupModule 中绑定 GEditor->GetSelectedActors()->SelectObjectEvent：

1
2
3
4
5

void OnActorSelected(UObject* SelectedObject) {
    if (AActor* Actor = Cast<AActor>(SelectedObject))
        if (CheckIsActorSelectionLocked(Actor))
            WeakEditorActorSubsystem->SetActorSelectionState(Actor, false); // 立即取消选中
}

七、Scene Outliner 自定义列#

🔌 嵌入编辑器#

通过 FSceneOutlinerModule 注册默认列类型：

1
2
3
4

FSceneOutlinerModule& Module = FModuleManager::LoadModuleChecked<FSceneOutlinerModule>("SceneOutliner");
FSceneOutlinerColumnInfo ColumnInfo(ESceneOutlinerColumnVisibility::Visible, 1,
    FCreateSceneOutlinerColumn::CreateRaw(this, &FSuperManagerModule::OnCreateSelectionLockColumn));
Module.RegisterDefaultColumnType<FOutlinerSelectionLockColumn>(ColumnInfo);

ShutdownModule 时 UnRegisterColumnType 注销。

⚙️ 功能实现#

继承 ISceneOutlinerColumn，实现两个核心方法：

  • ConstructHeaderRowColumn：列头显示一个锁图标 (SImage)
  • ConstructRowWidget：每行一个 SCheckBox，初始状态根据 CheckIsActorSelectionLocked 决定。勾选变化时调用 ProcessLockingForOutliner 锁定/解锁
1
2
3
4

// 从 TreeItem 中拿到 Actor
FActorTreeItem* ActorTreeItem = TreeItem->CastTo<FActorTreeItem>();
bool bLocked = SuperManagerModule.CheckIsActorSelectionLocked(ActorTreeItem->Actor.Get());
// CheckBox 状态变化回调 → ProcessLockingForOutliner(Actor, bShouldLock)

八、自定义 Slate 样式（图标）#

注册自定义 FSlateStyleSet，加载插件 Resources 目录下的 png 图标：

1
2
3
4
5

TSharedRef<FSlateStyleSet> StyleSet = MakeShareable(new FSlateStyleSet("SuperManagerStyle"));
FString IconDir = IPluginManager::Get().FindPlugin("SuperManager")->GetBaseDir() / "Resources";
StyleSet->Set("ContentBrowser.Delete", new FSlateImageBrush(IconDir / "iconDelete.png", FVector2D(16,16)));
StyleSet->Set("LevelEditor.LockSelection", new FSlateImageBrush(IconDir / "lock.png", FVector2D(16,16)));
FSlateStyleRegistry::RegisterSlateStyle(*StyleSet); // 启动时注册，关闭时反注册

使用时：FSlateIcon(FSuperManagerStyle::GetStyleSetName(), "ContentBrowser.Delete")

十、关键 UE5 API 速查#

用途 API
