岗位一：游戏客户端开发#

时长约 1.5~2 分钟，重点突出 UE5 Gameplay、3C、网络同步。

各位面试官好，我叫李睿杰，本科和硕士都就读于上海大学计算机工程与科学学院，本科专业是计算机科学与技术，目前在读软件工程硕士，预计明年六月毕业。

在游戏客户端方向，我有一个较完整的自研项目经历——基于 Unreal Engine 5 开发的多人在线射击游戏，支持通过 Steam 平台进行远程联机。在这个项目里，我用 UE 的 3C 系统实现了角色移动，并基于移动状态设计了层次动画状态机；框架层面我独立完成了菜单-大厅-赛场的完整游戏流程，包括玩家中途加入退出、多武器系统、角色 Buff 组件、比赛计分等模块。网络方面，我通过 UE 网络子系统实现了基于状态同步的多人联机，并落地了时间同步、客户端预测和延迟补偿，在不同网络环境下都能保持稳定且有沉浸感的联机体验。版本管理上使用了 Git LFS + 阿里云 CodeUp 管理资产与代码。

技术栈上，我主力语言是 C++，熟悉 STL 和多线程，也掌握 Python、Lua 等脚本语言，对游戏设计模式和基础渲染也有系统学习。

我是一个重度游戏玩家，涵盖主机、PC 和独立游戏，这让我对玩家体验有比较直接的感知。希望能把自己在 UE 客户端开发上的积累带到贵公司，参与到高质量游戏产品的研发中。谢谢。

岗位二：游戏客户端工具开发#

时长约 1.5~2 分钟，重点突出 UE 编辑器插件、MCP 工具链、Python 工程化能力。

各位面试官好，我叫李睿杰，上海大学软件工程硕士在读，预计明年六月毕业，本科同校计算机科学与技术专业。

工具开发方向，我做过一个比较有代表性的项目——UE 游戏编辑器插件 + MCP 服务。插件层面，我通过 Slate 和 EditorUtilityWidget 构建交互界面，实现了 Asset 批量操作、材质一键生成、关卡 Actor 批量管理等多种编辑器快捷功能，切实提升了日常开发效率。在此基础上，我进一步利用 UE 的远程执行功能，用 Python 将这些工具封装为 MCP Tool，让大模型对话终端能够直接执行 UE 快捷指令；还额外开发了 UE 窗口截屏、文档与源码查询等 MCP 工具，形成了一套 AI 辅助 UE 开发的完整工具链。

我同时有游戏客户端实战背景——自研了一款 UE5 多人射击游戏，完整实现了网络同步、客户端预测等底层特性，这让我对引擎的 Gameplay 框架和内存管理有更深入的理解，能从开发者视角出发设计更贴合实际需求的工具。

技术上我主力 C++ 和 Python，熟悉 UE 编辑器扩展体系，也具备 Web、数据库等工程化能力。我对"让开发者少做重复劳动"这件事很有热情，希望能加入贵公司，为工具链和开发效能建设贡献力量。谢谢。

反问问题（技术面）#

面试接近尾声时，挑 2~3 个提问，展示主动思考与对岗位的真实兴趣。根据面试过程中了解到的信息灵活选用。

关于技术与项目#

  1. “团队目前在客户端/工具链方向面临的最大技术挑战是什么？新人一般从哪类任务切入？”

    • 体现你想尽快上手、不怕难题的态度。

  2. “团队目前使用的引擎版本和核心技术栈是什么？有没有自研的底层模块或定制化的引擎改动？”

    • 说明你关注技术深度，也为后续学习做准备。

  3. “工具开发岗位和客户端/策划/美术等其他团队的协作方式是怎样的？需求一般怎么来？”（工具岗专用）

    • 展示对上下游协作的理解，也能判断岗位的实际工作模式。

关于成长与团队#

  1. “新人入职后一般有怎样的 onboarding 流程？是否会有导师带教或 code review 机制？”

    • 表明你重视规范和成长路径，而非只是"能干活"。

  2. “团队内部的技术分享或知识积累是怎么做的？”

    • 展示你对学习文化的重视，同时体现主动贡献的意愿。

关于岗位期望#

  1. “您觉得在这个岗位上，入职三到六个月算做得比较好的状态是什么样的？”
    • 帮你明确预期，同时让面试官感受到你的目标导向。

Tips：

  • 反问时保持简洁，问完等对方充分回答，不要连续抛多个问题。
  • 避免问薪资福利、加班情况等敏感话题（留到 HR 面再问）。
  • 如果面试过程中面试官已主动介绍了某个方面，就跳过对应的问题，换一个新的。
