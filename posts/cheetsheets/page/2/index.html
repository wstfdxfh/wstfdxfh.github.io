CppQuests

本文介绍C++的基础知识和笔试面试高频问题： 语言基础 strlen和sizeof sizeof：在编译期计算对象或类型所占字节数，对数组返回整个缓冲区大小，对指针返回指针本身大小，时间复杂度为 O(1)。 strlen：在运行期遍历字符直到遇到’\0’，返回 C 风格字符串长度（不含终止符），时间复杂度为 O(N)。 现代C++中，更加推荐使用stl，比如array或者vector 内联函数是什么，有什么好处和坏处？ **内联函数（inline）**是对函数的一种编译期建议，告诉编译器“在每个调用点直接展开函数体”，而不是做一次真正的函数调用。 好处在于： 消除调用开销：避免栈帧、参数拷贝和跳转开销，提升执行效率。 优化机会更多：展开后，编译器能做常量传播、死代码消除、循环展开等跨调用优化。 头文件定义安全：同一份 inline 函数可在多个翻译单元中定义而不违背 ODR（One‑Definition Rule）。 坏处在于： 代码膨胀：多处展开会增加可执行文件体积，可能影响 I‑cache 表现。 编译时间变长：更多展开和跨调用优化，加重编译负担。 展开不可控：编译器可根据函数体大小或递归等原则忽略 inline 建议。 调试不便：调用栈中看不到函数边界，单步调试和性能剖析不够清晰。 explicit作用 explicit：用于修饰单参数或多参数（带默认值）构造函数，禁止其进行隐式类型转换。 final作用 final：用于修饰虚函数或类，禁止虚函数在派生类中被覆写或禁止类被继承，提高设计安全性。 四种类型转换 static_cast：编译期类型转换，适用于已知安全转换（如基类↔派生类指针/引用、数值类型之间）时使用。 dynamic_cast：运行期安全向下转型，用于多态类层次，通过 RTTI 检查转换是否合法，失败时返回nullptr或抛出异常。 const_cast：添加或移除对象的const/volatile限定，用于调用需要非常量接口或暂时去除常量属性。 reinterpret_cast：最低安全级别的强制转换，用于不同类型之间的按位重解释（如指针与整数互转、不同指针类型互转），须谨慎使用。 命名空间 命名空间用于防止名称冲突并对代码进行逻辑分组，可以使用namespace 名称 { … }定义，在需要时通过using声明或限定名来访问其中的标识符。 函数指针 函数指针是一个存储函数地址的指针变量，可以用于动态调用不同函数，实现回调和策略模式等。定义形式为返回类型 (*指针名)(参数类型列表)，使用时可通过该指针调用对应签名的函数。 函数指针本质是指向函数的指针，它保存了一个函数的入口地址，可以在运行时将不同函数赋值给同一个指针变量，并通过该指针进行调用。 典型用途包括： 回调函数：当库或框架需要用户提供行为时，将函数指针作为回调参数传入。 策略模式：通过将不同的逻辑函数赋给函数指针，实现运行时选择算法或操作。 函数指针数组：管理一组同签名的函数，根据索引或条件灵活调用。 动态链接：从共享库（.so/.dll）中获取函数地址后，用函数指针调用。 例如，声明一个指向接收两个int返回int函数的指针： 1 2 3 int (*funcPtr)(int, int); int add(int a, int b) { return a + b; } int (*funcPtr)(int, int) = add; 常见使用场景 当某个函数需要在特定事件发生时调用用户提供的函数，可以将void(*)(参数列表)作为参数： 1 2 3 4 void processData(int data, void (*callback)(int)) { // 处理 data callback(data); // 事件发生时调用回调 } 静态局部变量、全局变量、局部变量的区别和使用场景 局部变量：在函数或代码块中定义，具有自动存储期，调用结束后销毁。 静态局部变量：在函数内部定义但加static，具有静态存储期，只初始化一次，并在多次调用间保留值。 全局变量：在函数外部定义，具有静态存储期且对整个程序可见，可用于跨函数共享数据。 使用场景: ...
