以下为GPT生成：#

下面这套流程假设你 已安装 Git 并准备把站点放在 ~/Sites/myblog（Windows 请自行换路径）。如果只想快速体验，可把「可选」步骤跳过。 示例命令在 终端/PowerShell 中输入；尖括号包围的内容 <…> 请按实际修改。

1 安装 Hugo Extended#

平台 推荐安装方式
macOS brew install hugo
Windows 10/11 choco install hugo-extended（需要 Chocolatey）
Ubuntu/Debian sudo apt-get install hugo 或下载官方 .deb
其他 Linux 从 [GitHub Releases] 下载对应压缩包，解压后把 hugo 放进 ~/bin 或 /usr/local/bin

验证：

1
2

hugo version
# Hugo Static Site Generator v0.125.x-EXT/...

必须是带 “-EXT” 的 Extended 版本，PaperMod 用到了 Sass/SCSS。 (Installation · adityatelange/hugo-PaperMod Wiki - GitHub)

2 创建新站点骨架#

1
2
3

hugo new site myblog
cd myblog
git init

3 添加 PaperMod 主题#

方式 A：Git 子模块（最简单，便于后续更新）

1

git submodule add --depth=1 https://github.com/adityatelange/hugo-PaperMod themes/PaperMod

方式 B：Hugo Module（Go 1.22+）

1
2

hugo mod init github.com/<your-git-id>/myblog
hugo mod get github.com/adityatelange/hugo-PaperMod

两种方式二选一即可。 (Installation · adityatelange/hugo-PaperMod Wiki - GitHub, adityatelange/hugo-PaperMod: A fast, clean, responsive Hugo theme.)

  ShowToc: true     # 文章侧边目录
  TocOpen: true
  assets:

  homeInfoParams:

    - name: 归档
      url: archives/
      weight: 5

更多可调参数、社交图标等详见 themes/PaperMod/README.md 与 Wiki。 (adityatelange/hugo-PaperMod: A fast, clean, responsive Hugo theme.)

6 本地预览（热重载）#

1

hugo server -D      # -D = 同时渲染 draft

浏览器打开 http://localhost:1313，修改文件会自动刷新。 (How to build a static site with Hugo - Hygraph)

7 生成静态网页#

1

hugo --minify       # 输出到 public/
  • GitHub Pages：把 public/ 推到 gh-pages 分支或 <user>.github.io 仓库根目录即可。
  • Netlify / Vercel：仓库根目录即项目，构建命令填 hugo --minify，发布目录 public.
  • 自托管 Nginx：直接把 public/ 内容复制到站点根路径。

8 常用可选配置#

需求 关键字段
文章 URL 末尾带 .html（Ugly URLs） uglyURLs: true
文章资源与 Markdown 做 Leaf Bundle 把文章目录改为 content/posts/hello-world/index.md，资源与 index.md 同级即可
主题更新（子模块方式） git submodule update --remote --merge
多语言 languages: 块下为每种语言设 weight、params

完成！🎉#

至此，你已经能在本地预览、并且手动或 CI/CD 生成 PaperMod 静态站点。后续只需：

  1. hugo new posts/<slug>.md 写新文章
  2. hugo server 本地预览
  3. hugo --minify && git push 发布
