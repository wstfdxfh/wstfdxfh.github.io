Network

本文介绍计算机网络的笔试和面试常见基础知识点和问题： 网络基础与协议分层 OSI层级 TCP/IP对应层 常见协议/技术 说明 数据链路层 (Layer 2) 网络接口层 Ethernet、Wi-Fi (IEEE 802.11)、PPP、ARP 负责在同一链路上传输帧，MAC寻址。ARP 用于 IP ↔ MAC 映射。 网络层 (Layer 3) 网络层 IP (IPv4 / IPv6)、ICMP、IGMP IP 提供逻辑寻址和路由；ICMP 用于差错报告（如 ping）；IGMP 管理组播。 传输层 (Layer 4) 传输层 TCP、UDP、SCTP TCP 提供面向连接、可靠传输；UDP 提供无连接、尽力而为的服务；SCTP 用于电信级应用。 应用层 (Layer 5–7) 应用层 HTTP/HTTPS、DNS、FTP、SMTP、POP3、IMAP、SSH、Telnet、SNMP 提供面向用户的具体服务：网页、文件传输、邮件、远程登录、网络管理等。 网络层 IP协议首部的构成 IP 协议首部（以 IPv4 为例）由多个字段组成，一般至少 20 字节（不含可选字段），格式如下： 版本（Version，4 bit） 指明 IP 协议版本，常见为 4（IPv4）或 6（IPv6）。 首部长度（IHL，Internet Header Length，4 bit） 表示 IP 首部的长度，单位为 4 字节。最小值为 5（即 20 字节），最大可到 60 字节。 服务类型（Type of Service / DSCP，8 bit） 原为 TOS，现在常用为 DSCP（区分服务代码点），用于服务质量（QoS）控制。 总长度（Total Length，16 bit） 整个 IP 数据报的长度（首部 + 数据），最大 65,535 字节。 标识（Identification，16 bit） 用于分片重组，标识一份 IP 数据报。 标志（Flags，3 bit） 控制分片： 位 0：保留 位 1：DF（Don’t Fragment，不分片） 位 2：MF（More Fragments，还有分片） 片偏移（Fragment Offset，13 bit） 数据报分片在原始报文中的相对位置，单位是 8 字节。 生存时间（TTL，Time To Live，8 bit） 防止分组无限循环，每经过一个路由器减 1，为 0 时丢弃。 协议（Protocol，8 bit） 指示数据部分使用的上层协议，如 TCP(6)、UDP(17)、ICMP(1)。 首部校验和（Header Checksum，16 bit） 只校验 IP 首部是否出错，不包含数据部分。 源地址（Source Address，32 bit） 发送方 IP 地址。 目的地址（Destination Address，32 bit） 接收方 IP 地址。 可选字段（Options，可变长） 用于测试、调试或安全相关，长度不定，若存在则首部长度 > 20 字节。 总结： IP 首部字段依次为 版本、首部长度、服务类型、总长度、标识、标志、片偏移、TTL、协议、首部校验和、源地址、目的地址、可选字段。 ...
